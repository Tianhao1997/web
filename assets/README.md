## Intended interpretation

The figure is a conceptual model of four Git contexts and selected operations between them. It is suitable for introducing how one person selects, records, and synchronizes changes.

## Limitations

- `localrepo` should be read as **local repository**.
- `git checkout` has several meanings; use `git switch` for branches and `git restore` for files in a beginner lesson.
- The `git merge` arrow is schematic. Merge combines compatible histories; it is not simply a file transfer from the repository to the working directory.
- `git pull` commonly performs a fetch followed by integration into the current branch, so both local history and working files may change.
- The figure omits branches, issues, pull requests, reviews, comments, and conflicts.
